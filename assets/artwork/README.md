# Original page artwork (required input)

Place the **original approved illustration** for each book page here, named:

- `page-01.png` through `page-24.png` (JPG/JPEG/WebP also accepted).

No generated geometric placeholders, AI substitutes, or blank mockups are accepted by the print build. The renderer fails closed if any page is missing.

Each artwork is placed across the full 8.625-inch page width and the upper 5.72 inches. Minimum source dimensions are therefore 2588 × 1716 pixels (300 DPI at placement size). Use RGB or RGBA. Keep all essential illustration details inside the safe area; backgrounds may extend to bleed.
