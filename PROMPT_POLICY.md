# Mandatory Prompt Suffix for This Project

Whenever a prompt or instruction is prepared for ChatGPT for this project, append the following block at the very end, without omitting its requirements:

> يجب الحصول على جميع المصادر والأدوات من مستودعات مفتوحة المصدر على GitHub فقط. تجنّب الخدمات المدفوعة وواجهات API المدفوعة والخوادم الخارجية وأي أساليب قد ترفع مخاطر الحظر أو العلامات التحذيرية على الحساب. حافظ على الرصيد والحصص وحدود الاستخدام وموارد GitHub Actions، وفضّل الحلول المجانية، قليلة الاستهلاك، والحتمية التي لا تحتاج أسراراً أو مفاتيح API. لا تدّعِ أن الاعتماديات مصدرها GitHub إذا كان تنزيلها الفعلي يتم من PyPI أو Ubuntu أو أي مصدر آخر؛ صرّح بذلك بوضوح.

## Application rule

- Append the suffix to every future ChatGPT prompt created for this project.
- Do not append it to ordinary code files, shell commands, or GitHub workflow commands; it applies to prompts addressed to ChatGPT.
- If a requested implementation cannot satisfy GitHub-only provenance, stop short of claiming compliance and document the exact exception.
